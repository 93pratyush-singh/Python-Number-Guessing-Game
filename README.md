# Python-Number-Guessing-Game

A simple Python-based Number Guessing Game where the computer randomly generates a number between 1 and 100, and the player has to guess it.

# Features

Generates a random number between 1 and 100
Provides hints:
  - Higher number Please!
  - Lower number Please!
Counts the number of attempts
Displays the correct number and total attempts after winning
Handles numbers greater than 100

# Technologies Used

Python
Random Module

# Example
Enter a number Between 1 to 100 : 50
Higher number Please !

Enter a number Between 1 to 100 : 75
Lower number Please !

Enter a number Between 1 to 100 : 63
You have guessed the number 63 correctly in 3 attempts
